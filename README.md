# Visualizzatore Gerber

Strumento per verificare e correggere i centri dei componenti nel file della pick and place, confrontandoli con i Gerber di produzione della scheda.

Stato: piano di sviluppo (`gerber_mvp_plan.md`, `IMPLEMENTAZIONE_BACKEND.md`) e scheletro del backend in Python/FastAPI con Docker. Il parsing userà [Gerbonara](https://gitlab.com/gerbolyze/gerbonara).
